# Сверка Office-ТЗ после main a616647

Это сверка кода, а не акт аппаратной приёмки. В main на момент начала работы
уже находились полноценная конвертация LibreOffice, защищённый worker, ресурсы,
выбор листов и общий подготовленный PDF, но обычные APK/SAF/Share Office не включали.
Новое продолжение подключает именно недостающий пользовательский маршрут.

| Требование | Реализация и проверяемый результат | Что остаётся |
| --- | --- | --- |
| Android 10+, SDK 29/36/36 | Сохранены Gradle-параметры; сборка/lint и эмуляторы API 29/36 в CI | Проверка на реальном телефоне |
| Локальный полноценный DOCX/DOC/XLS/XLSX | LibreOffice, ресурсы и 33 шрифта в обычных debug/release, без внешнего Office | Поддерживается документированное подмножество; не все старые/Strict/встроенные варианты |
| Выбор движка | Исследование движков, лицензий, размера и сопровождения; точные версии и источники | Соответствие Microsoft Office не заявляется без сравнений |
| Единый предпросмотр и печать | Один приватный PDF, готовая A4-раскладка, тот же PRINT-растеризатор и независимая копия очереди | Физическая проверка геометрии/ориентаций |
| Word | Многостраничность, смешанные ориентации A4, навигация, диапазон/копии; кириллица/списки/таблицы/изображения/колонтитулы в корпусе | Проверить конечную бумагу и собственные документы |
| Excel | Список до раскладки, все/подмножество в исходном порядке, Fit width с вертикальной пагинацией, новая версия предпросмотра | Предельные области/разрывы могут получить явный отказ; не сжимается весь лист в одну страницу |
| Ячейки/числа/даты/формулы | Форматирует полноценный движок; синтетические XLS/XLSX и PDF-проверки | Сохранённые результаты могут быть устаревшими, пересчёт может отличаться; предупреждение до задания |
| Приём файлов | Системный выбор и SEND; содержимое проверяет одноразовый worker, MIME/имя не считаются доказательством | SAF smoke перехватывает системный picker UI; реальный системный экран выбирает пользователь |
| Жизненный цикл | Приватный снимок, отмена зависшего provider, повторная подготовка без URI, пересоздание без grant; cleanup после смерти процесса | После смерти процесса требуется заново открыть исходник, автоматического возобновления нет |
| Ресурсы/ошибки | Прежние лимиты времени/размера/распаковки, RLIMIT и наблюдение общей памяти/диска, фиксированные сообщения до USB | Наблюдение RSS/диска не является жёсткой квотой/резервом ядра; глобальный OOM/LMKD/полный диск не испытаны |
| Приватность | Макросы запрещены, внешние ресурсы блокирует sandbox, документ не уходит на сервер и в JSON/log | INTERNET остаётся для updater по последующему явному требованию владельца |
| Общая очередь | Прежние HELD/активация, блокировка USB, отчёты, отмена/бумага; CAPT/HISCOA не меняются | Аппаратно проверить отмену и продолжение после бумаги |
| Сборка/лицензии/размер | Три ABI, обязательные ресурсы, notices, измерения debug/release; точный source bundle обязателен перед будущим распространением | CI-артефакты временные; будущий выпуск должен хранить исходники постоянно рядом с APK |
| Регрессии и обновление | Прежние PDF/image/PrintService/queue smoke; новый обычный user-route, PDF/PNG/JPEG через тот же приём, in-place debug upgrade API 29/36 | Release-ключ/updater и физический принтер не подменяются тестовой подписью/эмулятором |

Фактический статус и ссылки автоматических запусков фиксируются в новом PR
по точному SHA после завершения. Сборочный сценарий или тест, который ещё не
завершился, не считается успешным. Программный результат можно принять после
зелёных текущих CI; весь исходный запрос нельзя объявить аппаратно выполненным
до Canon LBP2900. Слияние и публикация релиза этой работой не выполняются.
