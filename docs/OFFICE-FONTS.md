# Фактический состав шрифтов Office-пробы

Это инвентаризация конкретного сборочного пакета, не завершённая лицензионная
приёмка APK. Проверен артефакт `libreoffice-native-arm64-v8a` №12595604938
из [исходной сборки 40179099832](https://github.com/alcovaibe/capt-usb-print/actions/runs/40179099832),
upstream `8221e31b3ac356a1623c672912a3d2b492f7e3d1` с адаптером Fit width.
Архив ZIP: 82 452 554 байта; сумма файлов пакета из inventory.json:
234 510 234 байта. Это не установленный размер приложения и не RAM.

## Что находится в assets

В `assets/unpack/user/fonts` лежат 33 TTF, всего 10 136 216 байт.
Имена семейств и сведения ниже прочитаны из таблицы `name` настоящих TTF;
общий файл `licenses/LICENSE` пакета проверен отдельно.

| --- | ---: | ---: | --- |
| Liberation Mono / Sans / Serif | 12 | 4 359 164 | Встроенная запись SIL OFL 1.1. |
| Liberation Sans Narrow | 4 | 484 232 | Отсылка к Liberation Fonts license; общий LICENSE содержит старый текст GPLv2 с исключениями. Нельзя автоматически приписывать этому семейству OFL остальных Liberation. |
| Caladea | 4 | 241 544 | Встроенная запись Apache 2.0. |
| Gentium Basic / Gentium Book Basic | 8 | 2 076 640 | Встроенные тексты SIL OFL 1.1 с reserved font names. |
| Carlito | 4 | 2 766 644 | Встроенная запись SIL OFL 1.1 с reserved font name. |
| OpenSymbol | 1 | 207 992 | Записи name ID 13/14 отсутствуют; окончательная цепочка исходника/лицензии этой проверкой не установлена. |

Это описание найденных записей, а не вывод о соблюдении всех условий
распространения. Для Narrow/OpenSymbol нужны точные соответствующие исходники
и условия именно данной версии, затем уведомления/доступ к исходникам в
распространяемом продукте. Остальные зависимости ядра тоже требуют полного
сопоставления с фактической сборкой. Наличие десяти файлов в каталоге licenses
не доказывает полноту такого сопоставления.

Источник OpenSymbol в закреплённом upstream —
[README рядом с OpenSymbol.sfd](https://github.com/LibreOffice/core/blob/8221e31b3ac356a1623c672912a3d2b492f7e3d1/extras/source/truetype/symbol/README).
Он описывает создание TTF из SFD; одного этого описания недостаточно для
закрытия лицензионного вопроса. Файлы шрифтов в этой работе не изменяются.

## Замены и воспроизводимость

`etc/fonts/fonts.conf` пакета также обращается к `/system/fonts` и содержит
generic-алиасы serif/sans-serif/monospace. Путь кеша fontconfig исправляется
backend на приватный workspace. Наличие TTF в assets не доказывает, какой
именно шрифт был выбран для конкретного фрагмента документа.

Шрифты Microsoft в этом списке не обнаружены. Отсутствующая гарнитура может
быть заменена; метрики, переносы и страницы могут отличаться от Microsoft
Office и между платформами. Встроенное предупреждение показывается до
подтверждения задания. Для приёмки нужны PDF с запрошенными/фактическими
гарнитурами, сравнение метрик и визуальная сверка; абсолютное совпадение
не заявляется. Обязательная установка Microsoft Office не требуется.

`tools/measure-office-probe-apk.py` получает имена и размеры файлов шрифтов
из реально собранного opt-in APK. Его отчёт дополняет эту проверку, но не
определяет семейство по таблице name и не проверяет лицензионные условия.
Состав обычного release по-прежнему не включает Office-ядро/эти шрифты.
Перед пользовательским включением остаются лицензионная приёмка, проверка
fallback и полная блокировка внешних ресурсов. Слияние и релиз не выполняются.
