# Лицензии, точные исходники и замены шрифтов Office

## Связь с конкретной сборкой

Закреплён LibreOffice 26.2.6.3, core
8221e31b3ac356a1623c672912a3d2b492f7e3d1. Нативная сборка сохраняет
config_host.mk, download.lst, autogen.input, контрольные суммы всех фактически
скачанных внешних архивов и найденные уведомления компонентов UnpackedTarball.
Это входы сборки, включая инструменты; не каждый вход является библиотекой APK.
inventory.json связывает каждый выходной файл с SHA-256 и ABI.

prepare-office-notices.py сверяет эти выходы, source-lock и все 33 TTF с
config/office-fonts.json. Неизвестный/изменённый шрифт или отсутствие исходных
уведомлений блокируют подготовку APK. Полные LICENSE/NOTICE/COPYING*, сведения
компонентов и источников, патч/адаптер CAPT и исходный OpenSymbol SFD попадают
в assets/office-licenses специального APK. Кнопка «Лицензии и исходники движка»
на внутреннем экране читает их локально. Юридические тексты не переводятся.

Отдельно проверяется `libc++_shared.so`: его SHA должен совпасть с оригинальным
файлом закреплённого NDK 29.0.14206865 для данного ABI. В APK и комплект исходников
сохраняются оригинальные NDK NOTICE/NOTICE.toolchain, уведомления sysroot,
source.properties и clang_source_info.md с точными ревизиями исходников toolchain.
native-runtime.json фиксирует все поставляемые `.so`, их SHA и DT_NEEDED:
каждая динамическая зависимость должна быть в пакете либо в явном списке
публичных Android-библиотек. Это не анализ статически включённых компонентов;
для них сохраняются LICENSE и входы фактической сборки.

Основной код LibreOffice имеет MPL 2.0; встроенные зависимости имеют собственные
условия. Поэтому одной корневой MPL недостаточно. Основание —
[страница лицензий TDF](https://www.libreoffice.org/licenses/) и **LICENSE
реальной сборки**, а не общий список зависимостей из другой версии.
Условия HISCOA/приложения GPLv3 сохраняются. Код адаптации содержит MPL-заголовок.

Отдельное задание CI формирует office-corresponding-sources.tar.gz с точным
core, исходниками CAPT/адаптацией, проверенными внешними архивами всех трёх ABI,
конфигурациями/инвентарями и редактируемым SFD-исходником Liberation Sans Narrow.
Его версия 1.07.6 закреплена коммитом 5462920fee502b688604472e65af49af951bdd56.
OpenSymbol SFD входит в core. SHA-256 каждого архива повторно проверяется;
недоступный/изменённый архив приводит к ошибке, а не подменяется новой версией.
REBUILD.txt объясняет сборку и установку изменённого APK со своим ключом.

Артефакт CI хранится 7 дней. **При будущем распространении бинарного выпуска
соответствующий комплект необходимо сохранить и предоставить рядом с ним**;
временная ссылка CI не является постоянной поставкой исходников. Эта работа
не публикует релиз и не включает Office в обычный release.

## Шрифты фактического пакета

| Семейство | Файлов | Условия и источник |
| --- | ---: | --- |
| Liberation Mono/Sans/Serif 2.1.5 | 12 | SIL OFL 1.1, правообладатели Google/Red Hat; точный архив и SHA в download.lst. |
| Liberation Sans Narrow | 4 | Отдельная Liberation license: GPLv2 с исключениями и полным дополнительным текстом. Это **не OFL**. Архив 1.07.6 содержит TTF с внутренней строкой версии 1.07.5; сохраняются обе фактические записи. |
| Caladea | 4 | Apache 2.0, Huerta Tipográfica. |
| Carlito | 4 | OFL 1.1, tyPoland Łukasz Dziedzic, reserved font name Carlito. |
| Gentium Basic/Book Basic | 8 | OFL 1.1, SIL International, reserved font names. |
| OpenSymbol 102.12 | 1 | LGPLv3+, исходный SFD/авторы из закреплённого core; LGPL и GPL сохранены. |

Для OpenSymbol в TTF нет name ID 13/14: это не означает отсутствие лицензии.
Дополнительное первичное основание —
[пояснение разработчика в архиве TDF](https://listarchives.libreoffice.org/global/dev/2012/msg09683.html).
Уведомления сохраняют всех авторов из name ID 0 и исходный SFD. Историческое
пояснение не выдаётся за новую персональную юридическую гарантию правообладателя.
Полные исключения Narrow берутся из LICENSE и
[исходного проекта](https://github.com/liberationfonts/liberation-sans-narrow/blob/5462920fee502b688604472e65af49af951bdd56/License.txt).
Шрифты не изменены и не переименованы; embedding-биты TTF записаны отдельно,
они не заменяют условия лицензии. Состав остальных зависимостей сохранён полностью.

## Реальная замена и границы проверки

В приватном fontconfig worker заданы сильные алиасы Arial → Liberation Sans,
Times New Roman → Liberation Serif, Courier New → Liberation Mono,
Calibri → Carlito, Cambria → Caladea, Arial Narrow → Liberation Sans Narrow.
Шрифты Microsoft не поставляются. Недостающие символы используют fallback;
например, Caladea этого пакета не содержит кириллицу. Системные шрифты Android
сохранены для покрытия символов, поэтому результат может зависеть от устройства.

Внутренний экран до подтверждения печати объясняет замены и влияние на переносы/
число страниц. Это не список фактических замен каждого фрагмента пользовательского
документа. Проверка Poppler записывает actual fontspec латинских меток двух
синтетических Word-PDF, отдельно проверяет извлечённую кириллицу. Переносить
это на все глифы/шрифты/документы нельзя. Требуется просматривать готовый результат.
Предпросмотр и печать читают один PDF, поэтому повторной подмены шрифтов при
отправке в очередь нет. Сверка с Microsoft Office и физическая печать не заявляются.
