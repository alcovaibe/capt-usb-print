# JNI bootstrap LibreOffice для инструментальной пробы

Четыре Java-файла `org/libreoffice/kit` сохранены без функциональных изменений
из LibreOffice 26.2.6.3, коммит `8221e31b3ac356a1623c672912a3d2b492f7e3d1`,
каталог `android/Bootstrap/src/org/libreoffice/kit`. Сохранены исходные заголовки
MPL 2.0 и полный текст лицензии в COPYING.MPL.

Исходник: https://github.com/LibreOffice/core/tree/8221e31b3ac356a1623c672912a3d2b492f7e3d1/android/Bootstrap/src/org/libreoffice/kit

Эти обёртки и OfficeEngineSmoke компилируются только в debug для ранней проверки
совместимости Java/Kotlin/Android API. Обычный debug не содержит нативного ядра
и не объявляет JNI-пробу в манифесте. Запуск пробы требует отдельной сборочной
опции `officeEngineDir`, готового пакета ядра и четырёх синтетических assets.
В release этот исходный набор не включается.

Upstream bootstrap перенаправляет stdout/stderr в Android log и пишет путь
инициализации. Проба открывает исключительно встроенные синтетические файлы.
Перед производственным конвертером необходимо заменить этот bootstrap
вариантом для изолированного сервиса и отключить журналы, способные содержать
пути/сообщения пользовательских документов. Пользовательские URI здесь не
принимаются.
